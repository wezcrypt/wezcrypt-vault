# Open Source & Privacy Notice

WezCrypt Vault is an open-source project.

The complete source code is publicly available for anyone to inspect, review, audit, modify, and verify:

https://github.com/wezcrypt/wezcrypt-vault

The application is designed to operate locally on your device.

Any passwords, files, encryption keys, notes, or other data you enter into the application are not intentionally transmitted to the developer or to any external server operated by the project.

The project does not include a hidden account system, analytics service, advertising tracker, or developer-controlled database intended to collect your private vault data.

Because WezCrypt Vault is open source, users and security researchers can independently inspect the code and verify how their data is handled.

## Contributions

Community contributions are welcome.

You are free to modify the code, improve existing features, fix bugs, or add new features.

If you create something useful, you can submit it to the project through a Pull Request.

Contributions that are useful, secure, and compatible with the goals of WezCrypt Vault are welcome and can be accepted into the project without unnecessary restrictions.

The goal is to keep WezCrypt Vault open, transparent, secure, and continuously improved by the community.

For maximum transparency, always review the source code of the version you are using and download releases from the official project repository.
